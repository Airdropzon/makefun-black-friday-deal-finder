DealHound — a static Black Friday deal finder with 40 real deals, each checked on 27 Nov 2026 at its store, with sale price, usual price, discount, a verdict on whether it is really a deal, and a link to the store. Searchable and filterable by category, store and discount; works on desktop and phone from static files with no network request.

## Run it

```sh
python3 -m http.server 8080 -d app
```

Lalu buka http://localhost:8080 di browser. (Jangan tulis perintah lain yang butuh install.)
